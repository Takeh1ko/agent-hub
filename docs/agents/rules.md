# Правила для моделей-исполнителей и ревьюеров (agent-hub)

Этот текст вставляется в начало каждого задания. Карточка задачи идёт следом — она главнее общих слов, но не этих правил.

## Окружение
- Ты в отдельной копии репозитория (git worktree) на ветке `agent/<задача>`. Выходить за её пределы нельзя
  (opencode всё равно откажет) — всё нужное есть в репозитории: `docs/spec.md`, `docs/tasks/`, код, тесты.
- Python: `/home/takehiko/Projects/Python/agent-hub/.venv/bin/python` (3.12, textual, aiogram, pytest уже стоят).
  Тесты: `/home/takehiko/Projects/Python/agent-hub/.venv/bin/python -m pytest -q <пути>`.
  Зависимость, которой нет в `pyproject.toml`, — не добавлять; напиши в отчёте.
- **Настоящие данные не трогать:** `~/.local/share/opencode/opencode.db`, `~/.gemini/…`, чужие процессы, git-репозитории
  других проектов. В тестах — только фейки во временном каталоге (`tests/conftest.py` подменяет `HOME`).
  Код, который читает чужие SQLite, открывает их строго `file:…?mode=ro`.
- Сеть: никакой (Telegram в тестах — фейковый бот/сессия aiogram). Процессы не убивать, демоны не запускать.

## Код
- Меняй только файлы из «Можно менять» карточки. Нужно больше — напиши в отчёте, не меняй.
- **Карточки задач (`docs/tasks/**`) не трогать никогда** — ни свою, ни чужие: противоречие в карточке — в отчёт,
  решает архитектор. Тесты на текст документации/карточек запрещены — тесты проверяют код.
- Стиль: Python 3.12, аннотации типов, `from __future__ import annotations`, dataclasses, stdlib `sqlite3`;
  комментарии и тексты интерфейса — по-русски, коротко. Функции чтения — чистые, без глобального состояния;
  время — параметром (`now`/`clock`), чтобы тесты шли на фиксированных часах.
- Интерфейс из карточки (имена, сигнатуры, поля JSON) — контракт для следующих задач: не переименовывать.
- Не подгонять код под тест костылями; тест, который проходит при сломанной логике, — брак (ревью это ищет).

## Коммит — обязателен
- Первый коммит — как только есть работающий кусок, дальше — ещё коммиты; в конце `git status` чистый.
- `git add <пути>` поимённо (никогда `-A`/`.`), сообщение из карточки, по-русски.
- Задача без коммита не принимается: ворота проверяют `base..HEAD`, незакоммиченная работа = работы нет.

## Отчёт (последнее сообщение)
Ровно такие разделы:
1. **Сделано** — файлы и что в них.
2. **Тесты** — команда и последние строки вывода как есть.
3. **Не сделано / под вопросом** — честно; не проверил — так и пиши.
4. **Коммиты** — `git log --oneline base..HEAD`.

## Ревьюеру
- Ты в новой сессии и не видел работы исполнителя. Проверь по карточке: интерфейс, приёмку, запреты; ищи тесты-пустышки
  (проходят при сломанной логике — проверь, сломав логику локально и откатив), гонки, утечки дескрипторов SQLite,
  блокирующие вызовы в async-коде TUI/бота, чтение чужих БД не в `mode=ro`.
- Каждое замечание — с файлом, строкой и конкретным исправлением. Стиль/вкус — только `low`.
